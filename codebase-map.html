Resumen

Foto verificada en código · ver citas ruta:línea

ClockLog es un temporizador Pomodoro multiusuario + planificador semanal desacoplado: dos mitades (timer, plan) que solo comparten user/tag/setting y son físicamente borrables (backend/app/main.py:51-56, docs/architecture.md:31-36). Backend FastAPI async + PostgreSQL 16, frontend Next.js 16 App Router, en una VPS con Docker Compose; nginx + certbot corren fuera de Compose. Registro abierto con email verificado (G-6), JWT bearer + bcrypt, email vía Resend con httpx plano sin SDK.

Rangos de instantes UTC; un POST por bloque con UUID cliente (idempotencia offline).

Convenciones y deuda

Patrones detectados en código + AGENTS.md

ÁreaConvención / riesgo
TiempoUTC + aware siempre; duraciones derivadas, nunca almacenadas (inv. 5-6). Bloque tras medianoche = día de inicio (inv. 7). Riesgo: cualquier fecha en servidor salvo plan rompe el invariante.
TimerCliente puro, 1 POST/bloque, localStorage recovery, abortados se guardan (inv. 1-4, 8-9). Auto-start OFF por defecto: break arranca al cerrar LabelSheet.
Módulostimer/plan sin imports cruzados ni FK cruzadas ni vocabulario Pomodoro en plan (inv. 11-13, tests mecánicos). Fase 3 (checkbox timer en entries) exige renegociar 12-13 por escrito — no implementar.
BackendRouters finos → service.py (inv. 16). Schemas Pydantic en borde, sesiones async, {code} estable, ruff 100 col.
FrontendMobile-first tab bar 56px (overlays en bottom-16 md:bottom-4) · Server Components por defecto · PrimaryButton único filled · tags único color saturado · tokens solo en globals.css · sin any.
SeguridadSin framework auth; sin cookie (CORS credentials off); registro siempre abierto (nginx restringe); login plano en tiempo; 204 ambiguo en forgot/resend; cambio pass revoca sesiones.
Deuda / vigilanciaRate-limit in-memory (ratelimit.py:17-21) — se pierde al reiniciar, no escala a N réplicas. Sin tests UI exhaustivos por decisión (lógica día-frontera prioritaria). Cabeceras licencia con variante plan — romperla tumba test_independence.
No existe: websockets, premium (is_premium prohibido, inv. 15), export, charts, vistas semana/mes de historial, entrada manual, RRULE, SDK Resend, Makefile/scripts deploy. Pedirlos es expansión de alcance.
