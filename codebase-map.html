ClockLog · mapa del código

Aplicación multiusuario de timer Pomodoro e historial más un calendario semanal independiente. El navegador mantiene el timer y su cola offline; FastAPI persiste datos, autentica y consulta Postgres. Corre en un VPS con Docker Compose y nginx.

Convenciones y deuda

  • Timer y plan son independientes, con tests de borrado físico e imports. backend/tests/test_deletability.py · backend/tests/test_independence.py
  • Next se ejecuta como servidor Node, pero no hay Route Handlers, Server Actions ni fetch de datos de usuario en Server Components. frontend/next.config.ts:3 · frontend/lib/api/client.ts:109
  • La API y los tipos del frontend son dos descripciones manuales del contrato; si se cambia un schema, revisar el tipo correspondiente. backend/app/plan/schemas.py:27 · frontend/lib/api/plan.ts:24
  • El rate limit es memoria del proceso; aumentar réplicas cambiaría su semántica. backend/app/core/ratelimit.py:20
  • Drift documental: el manual raíz dice que las vistas de historial semana/mes no están construidas; el código actual las implementa. AGENTS.md · frontend/components/timer/HistoryPage.tsx:62
